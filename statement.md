# Project Statement

## Python Bill Calculator

The **Python Bill Calculator** is a beginner-level Python project designed to calculate the tax amount and the final bill total based on the bill amount entered by the user.

The program asks the user to enter the **subtotal (bill amount)** and the **tax percentage**. It then calculates the tax using the formula:

**Tax = Subtotal × Tax Rate / 100**

After calculating the tax, the program calculates the final amount using:

**Total = Subtotal + Tax**

Finally, the program displays a clear bill summary containing the subtotal, tax amount, and total bill amount.

## Objective

The main objective of this project is to understand and apply basic Python programming concepts such as:

- Taking input from the user
- Using variables
- Converting input into floating-point numbers
- Performing arithmetic calculations
- Using f-strings for formatted output
- Formatting decimal values to two decimal places

## Example

For a bill amount of **₹1000** and a tax rate of **18%**:

- Subtotal = ₹1000
- Tax = ₹180
- Total = ₹1180

## Conclusion

This project provides a simple practical example of how Python can be used to automate everyday calculations. It is suitable for beginners and helps build a foundation for developing larger Python projects.
